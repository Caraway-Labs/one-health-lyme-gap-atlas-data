## Field ownership and release boundary

Source governance owns publisher/product/version/vintage/run/artifact authorization. Canonical tick normalization owns scientific taxon, pathogen, life-stage, method and testing-scope IDs and source-specific proof. #157 owns quality and propagation. #158/#159 own derived methodology, evidence basis, result revision, eligibility and limitations. #190 owns semantic identities, grain, time, unit/denominator and value-state definitions. #191 owns metadata IDs/revisions and interpretation. #193 owns lineage edges and safe references. #192 only binds these authorities for specific source families and validates the bindings.

The current `semantic_release.py` builder and V071/V072 storage remain the authoritative five-slot, 3,144-county, 14-observation release. V100–V102 result stores remain DEV/internal. This matrix neither adds a slot or row to the release nor changes the pointer, public views, migrations, or Alpha isolation. #194 owns approved consumer/public projections; #195 owns broader generated cross-version and release compatibility gates.
