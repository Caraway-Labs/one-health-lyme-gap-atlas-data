### Exact added read-only SQL

Identity query, run separately on each named profile:

```sql
SELECT CURRENT_TIMESTAMP() AS AUDIT_TIME, CURRENT_USER() AS AUDIT_USER,
 CURRENT_ROLE() AS AUDIT_ROLE, CURRENT_DATABASE() AS AUDIT_DATABASE,
 CURRENT_WAREHOUSE() AS AUDIT_WAREHOUSE;
```

For PROD replace every `_DEV` with `_PROD`:

```sql
SELECT CURRENT_TIMESTAMP() AS AUDIT_TIME,
 (SELECT RELEASE_ID FROM ONE_HEALTH_LYME_GAP_ATLAS_DEV.PRESENTATION.CURRENT_RELEASE_V LIMIT 1) AS RELEASE_ID,
 (SELECT COUNT(*) FROM ONE_HEALTH_LYME_GAP_ATLAS_DEV.PRESENTATION.CURRENT_COUNTY_ATLAS_V) AS COUNTY_ROWS,
 (SELECT COUNT(*) FROM ONE_HEALTH_LYME_GAP_ATLAS_DEV.KNOWLEDGE_GRAPH.PAPERS) AS PAPER_ROWS,
 (SELECT COUNT(*) FROM ONE_HEALTH_LYME_GAP_ATLAS_DEV.KNOWLEDGE_GRAPH.RETRIEVAL_CORPUS_UNITS) AS CORPUS_ROWS;

SELECT CURRENT_TIMESTAMP() AS AUDIT_TIME, TABLE_SCHEMA, TABLE_NAME, ROW_COUNT
FROM ONE_HEALTH_LYME_GAP_ATLAS_DEV.INFORMATION_SCHEMA.TABLES
WHERE TABLE_SCHEMA IN ('PRESENTATION','CONFORMED','KNOWLEDGE_GRAPH')
 AND (TABLE_NAME ILIKE '%DERIVED_RESULTS%' OR TABLE_NAME ILIKE '%CLIMATE%'
      OR TABLE_NAME ILIKE '%NLCD%' OR TABLE_NAME ILIKE '%LAND_COVER%')
ORDER BY TABLE_SCHEMA, TABLE_NAME;
```
